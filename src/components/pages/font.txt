# ─── Webict Capital — Typography System ─────────────────────────────────────
# This file defines the standard fonts for the entire project.
# Any new component or page MUST use these fonts. No ad-hoc font choices.

## 1. Brand / Logo
   Font:    Playfair Display
   Import:  Google Fonts
   Weights: 700 (Bold)
   Use for: Logo text only ("Webict Capital.")
   CSS:     font-family: var(--wc-font-brand)
   Note:    Do NOT modify logo typography, size, weight, or spacing.

## 2. Display / Page Headings
   Font:    Playfair Display
   Import:  Google Fonts
   Weights: 700 (Bold)
   Use for: Large page titles, hero titles, major editorial headings only.
            Examples: "PSX Market Overview", "Stocks", "SIP Calculator", "Glossary"
   CSS:     font-family: var(--wc-font-display)
   Note:    Do NOT use for table headers, small labels, buttons, nav items,
            form fields, chart labels, ticker symbols, or financial numbers.

## 3. UI / Body / Product Text
   Font:    Inter
   Import:  Google Fonts
   Weights: 400, 500, 600, 700, 750, 800
   Use for: Body text, descriptions, navbar, buttons, cards, dashboard headings,
            section headings, labels, forms, tables, chart labels,
            stock symbols/tickers, all financial data.
   CSS:     font-family: var(--wc-font-body)

## 4. Numbers / Financial Data
   Font:    Inter (NOT monospace)
   Use for: Prices, percentages, P/E, EPS, market cap, volume, index values,
            ratios, table numeric cells, KPI values.
   CSS:     font-family: var(--wc-font-data)
            font-variant-numeric: tabular-nums;
            font-feature-settings: "tnum" 1;

## 5. Stock Symbols / Tickers
   Font:    Inter (NOT monospace)
   Style:   font-size: 12-13px, font-weight: 700-750, text-transform: uppercase,
            color: var(--wc-primary)
   CSS:     font-family: var(--wc-font-body)

# ─── CSS Custom Properties (defined in index.css) ──────────────────────────

   --wc-font-brand:   "Playfair Display", serif
   --wc-font-display: "Playfair Display", serif
   --wc-font-body:    "Inter", sans-serif
   --wc-font-data:    "Inter", sans-serif

# ─── Rules ──────────────────────────────────────────────────────────────────

   1. NEVER use JetBrains Mono or any monospace font for public UI text.
   2. NEVER go below 11px for any readable text.
   3. Financial numbers MUST use Inter with tabular-nums font features.
   4. All uppercase labels MUST have letter-spacing >= 0.06em.
   5. Body/description text MUST have line-height >= 1.5.
   6. Playfair Display is ONLY for logo and large page/hero headings.
   7. Ticker symbols use Inter (not monospace).
   8. Use only the approved CSS variables — no ad-hoc fontFamily declarations.
